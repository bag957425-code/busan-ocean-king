# 내일의 해양왕

부산 지역의 해양 생태계를 쉽고 재미있게 배우는 교육·탐험 웹앱입니다.

## 주요 기능

- 부산 해양 생물 탐험 및 가상 도감 수집
- 낚시 미니게임과 상세 생물 정보
- AI 사진 인식을 활용한 실제 해양 생물 확인
- 해양 환경 퀴즈와 쓰레기 줍기 인증 미션
- 친구 추가, 활동 모집 및 커뮤니티 게시물
- 한국어·영어 언어 설정

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버로 실행합니다.
